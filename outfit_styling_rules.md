# Outfit Styling Rules

Basic, generic rules for the outfit recommender. They decide which catalogue
items go **together**; they do not change any item's style (that stays in
`style_taxonomy_men.md` and `style_taxonomy_women.md`). The same rules apply to
the men's and the women's catalogue.

## 1. What an outfit is made of

| Outfit type | Pieces |
| --- | --- |
| Western | top + bottom + footwear (+ 1 or 2 accessories, optional jacket or blazer) |
| One-piece | dress, gown or jumpsuit + footwear (+ 1 or 2 accessories) |
| Indian | kurta / kurta set, saree or lehenga + ethnic footwear (+ 1 or 2 ethnic accessories) |
| Co-ord | co-ord set + footwear (+ 1 or 2 accessories) |

## 2. Must match (hard rules)

1. **Same gender**: men's items with men's items, women's with women's.
2. **Same occasion family**: casual, formal or office, party, festive or wedding,
   active or gym. Do not mix, for example, gym wear with festive wear. An item
   with no real occasion tag (only the default "casual") fits the occasions its
   style is worn for:

   | Occasion | Untagged items of these styles count |
   | --- | --- |
   | casual | every style |
   | formal | classic, minimalist, glam |
   | party | glam, edgy, classic, minimalist, streetwear, ethnic fusion |
   | festive | traditional, ethnic fusion, glam, boho |
   | active | sporty, streetwear |
3. **Compatible styles**: pieces share the same style, or a pair from this list:

   | Style | Goes with |
   | --- | --- |
   | minimalist | classic, streetwear, sporty |
   | classic | minimalist, glam |
   | streetwear | minimalist, sporty, edgy |
   | boho | ethnic fusion, minimalist |
   | sporty | streetwear, minimalist |
   | glam | classic, traditional, edgy |
   | ethnic fusion | traditional, boho, glam |
   | traditional | ethnic fusion, glam |
   | edgy (women) | streetwear, glam |

4. **Size**: every piece is in stock in the size the user asks for.

## 3. Colour

1. **Neutrals go with everything**: black, white, grey, navy, beige.
2. **At most two non-neutral colours** in one outfit.
3. **Safe pairs**: navy + white, black + white, beige + white, olive + beige,
   blue + white, maroon + beige, black + red, pink + white.
4. **Avoid**: two different bright colours together (red + green, orange + pink,
   purple + yellow).
5. **One colour family** (tonal, e.g. all blues or all beiges) is always allowed.

## 4. Pattern

1. **One patterned piece per outfit** (print, stripes, checks, floral, embroidery);
   everything else solid.
2. A plain neutral piece is the safest partner for a patterned one.

## 5. Fit

1. **Balance the shape**: an oversized or loose top goes with a slim or straight
   bottom; a fitted top goes with a wide, flared or relaxed bottom.
2. Avoid oversized on oversized, except in streetwear.

## 6. Fabric and season

1. Light fabrics together (cotton, linen) for summer; heavy fabrics together
   (wool, fleece, velvet) for winter.
2. Do not pair a festive fabric (silk, velvet, zari) with a gym fabric (polyester
   activewear).

## 7. Price

Keep pieces in the same or a neighbouring price band (cheap with affordable,
affordable with luxury; not cheap with luxury).

## 8. Choosing the best outfits

1. Keep only outfits that pass every rule in section 2.
2. Score the rest: +1 for each rule in sections 3 to 7 that the outfit follows.
3. Show the highest-scoring outfits, and do not repeat the same item in every
   suggestion: a garment appears in only one outfit of a set; a footwear or
   accessory item in at most three (some styles have few shoes).
4. With each outfit, show one short reason (for example "navy + white, one
   printed piece, smart casual").
